# Dr. Motors — Sistema de Gestión de Taller

Sistema web para gestión de taller automotriz. Permite administrar vehículos, cotizaciones, órdenes de trabajo, inventario y trabajadores.

## Stack

- **Frontend**: React + TypeScript + Vite + CSS Modules
- **Backend**: Node.js + Express
- **Base de datos**: Firebase Firestore
- **Auth**: Firebase Authentication
- **Deploy**: Firebase Hosting + Cloud Run (GCP)

## Estructura

drmotors-app/

├── client/   → Frontend React

└── server/   → API Express


## Scripts

```bash
# Frontend
cd client && npm run dev

# Backend
cd server && npm run dev
```
